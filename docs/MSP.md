# MSP usage and lifecycle

`StartMSP` launches `muse serve`, negotiates `initialize` and sends `initialized`. It owns the process; startup context controls the handshake, and `Close` closes stdin, waits up to its deadline (two seconds by default), then kills and reaps. Stdout is reserved for JSON-RPC; stderr is discarded. Each `Call` correlates its response by request ID; remote errors retain the code and data. A cancelled call stops waiting but does not undo an admitted command. A process failure during a request leaves its outcome unknown; callers must not retry side effects under a fresh command ID blindly.

Use `Notifications()` for all session events and route by the event's session/turn/item fields. All events retain `Params` and the full `Raw` message, including unknown event kinds. A fast terminal may arrive before `turn/start` returns; the host keeps it until `Wait`. `Turn.Wait` is a single-consumer operation; cancellation stops waiting, not the native turn. `Interrupt` and `Cancel` submit distinct commands, then the caller should wait for the terminal. A returned terminal has an open vocabulary; check it rather than treating an unknown value as success.

`Requests()` contains server-initiated requests. `Respond(nil)` sends `{}` as a presentation receipt; it does not make a decision. Send a decision using the exact server-supplied `approvalId`, `choiceId`, and `currentRequirementId`, with `DecideApproval`. Forward questions and submit answers using their server IDs. If presentation is unavailable, use an error response and do not claim success. On reconnect inspect pending requests before responding. User-input dialogs are off unless the host caller explicitly enables them.

MSP schema version 1 is accepted. Fingerprint differences are returned in `Warnings`, not treated as errors. No experimental capability is requested. The request and notification queues are bounded; if not drained, overflow closes the connection. An MSP `view/gap` must be surfaced and reconciled by the caller; cursors are opaque, and this version does not perform gap repair automatically. Use raw `Call` for further supported stable methods and preserve raw payloads for unrecognized additions.
